# Релиз MAUverse

Целевая площадка — **RuStore, Android**. iOS в текущий релиз не входит.

## 1. Замена существующего Mauverse

Сейчас в RuStore опубликован старый **Mauverse** (`com.pmi.mauverse2`, издатель — Мурманский Арктический Университет, версия 1.1.0, не поддерживается). MAUverse должен заменить его.

Есть два пути:

### A. Обновление существующего приложения (предпочтительно)

Нужны:

- доступ к аккаунту RuStore университета;
- **ключ подписи** старого APK/AAB (`com.pmi.mauverse2`) и пароли к нему;
- текущий `versionCode` из RuStore Консоли;
- package остаётся `com.pmi.mauverse2`.

Тогда новый APK публикуется как обновление, пользователи получают его поверх старого приложения. `versionCode` новой сборки должен быть больше текущего.

### B. Новое приложение с тем же названием

Если ключ подписи утерян или обновление невозможно:

- выбрать новый package (например, `com.horizon_spark.mauverse` или `ru.mauniver.mauverse` — по согласованию с вузом);
- согласовать с университетом снятие/переименование старого Mauverse в RuStore, чтобы не было двух приложений с одинаковым названием;
- учесть, что старые пользователи не получат автообновление и должны будут установить новое приложение.

До решения по package **не загружать APK в RuStore**.

Текущий `android.package` в `app.json` (`com.horizon_spark.ScheduleMASU`) — рабочее значение, не финальное.

## 2. Окружение EAS

В EAS Environment Variables должны быть заданы:

| Переменная | development | preview | production |
|---|---|---|---|
| `EXPO_PUBLIC_API_BASE_URL` | адрес прокси | `https://srv-project.mspu.edu.ru/api` (HTTP — только пока TLS не установлен) | **обязательно `https://…/api`** |
| `EXPO_PUBLIC_ALLOW_HTTP` | не задавать | `1` только для HTTP-fallback; после установки TLS не задавать | не задавать |
| `APP_VARIANT` | задаётся в `eas.json` | задаётся в `eas.json` | задаётся в `eas.json` |

`app.config.js` не даст собрать ни один EAS-профиль без `EXPO_PUBLIC_API_BASE_URL`, а production — без HTTPS. `src/api/client.ts` дополнительно проверяет это в рантайме.

## 3. Сборка для RuStore

```bash
npx eas-cli@latest build --platform android --profile production
```

- `eas.json` для production собирает **APK** (RuStore принимает APK и AAB; APK проще по подписи).
- `autoIncrement: true` — versionCode увеличивается на стороне EAS.
- Для обновления старого Mauverse проверьте, что удалённый versionCode больше текущего.
- Подпись хранится в EAS. Если используется старый ключ Mauverse — загрузите его в EAS credentials.
- Сделайте резервную копию credentials:
  ```bash
  npx eas-cli@latest credentials -p android
  ```
- Потеря ключа подписи = невозможность обновлять приложение в RuStore.

## 4. HTTPS

Production-приложение обязано ходить только по HTTPS:

- в `EXPO_PUBLIC_API_BASE_URL` — домен с доверенным сертификатом;
- `usesCleartextTraffic` для production выключается автоматически (`app.config.js`);
- серверная часть: TLS-оверлей nginx, сертификат и деплой описаны в README `api/`.

Текущий тестовый контур:

```text
EXPO_PUBLIC_API_BASE_URL=https://srv-project.mspu.edu.ru/api
```

Домен и сервер доступны только из сети университета, сертификат — корпоративный
CA. Тестовое устройство должно доверять корневому сертификату CA: на iOS его
нужно установить и включить полное доверие, на Android — иметь managed-профиль
с CA в системном хранилище или development build с network security config.
Expo Go может не доверять пользовательскому CA.

Пока публичного домена и внешнего доступа нет, preview-сборка может работать по
HTTP с `EXPO_PUBLIC_ALLOW_HTTP=1`. В production этот флаг не задаётся. Для
публикации в RuStore потребуется публично доверенный сертификат и внешний
HTTPS-доступ, а не только внутренний контур.

## 5. Чек-лист RuStore

- [ ] Аккаунт разработчика RuStore и черновик приложения с финальным package name
- [ ] Решение: обновление `com.pmi.mauverse2` или новое приложение
- [ ] Подписанный APK (production)
- [ ] Иконка, название, короткое и полное описание
- [ ] Скриншоты телефона
- [ ] Категория и возрастной рейтинг
- [ ] Политика конфиденциальности (публичный URL)
- [ ] Контакты поддержки (`mauverse@mauniver.ru` или актуальный)
- [ ] Тестовый аккаунт/инструкция для модерации, если требуется
- [ ] Проверка установки и обновления версии (versionCode +1)

## 6. QA перед загрузкой

- [ ] Вход: верный/неверный LDAP, пустые поля, нет сети
- [ ] Вход: при открытой клавиатуре видны логин, пароль и кнопка «Войти»
- [ ] Истечение access-токена и автоматический refresh
- [ ] Перезапуск приложения с сохранённой сессией
- [ ] Выход: очистка токенов, выбора и кеша
- [ ] Расписание группы, преподавателя, аудитории
- [ ] Быстрый выбор преподавателя/аудитории из шапки и пустого состояния
- [ ] Переключение недель и выбор периода
- [ ] Подгруппы: метки в карточках, основные группы в профиле
- [ ] Пустой день и пустая неделя
- [ ] Офлайн: кеш + баннер, повторная загрузка
- [ ] Выход без сети: локальная сессия всё равно очищается
- [ ] Маленький экран и «чёлка»
- [ ] Крупный системный шрифт (130–200%): tab bar, дни недели, карточки, модалки
- [ ] TalkBack: карточка занятия читается одним блоком, кнопки и состояния озвучены
- [ ] Модалки не уходят под статус-бар и навигационную панель
- [ ] Быстрое переключение факультета/курса: группы соответствуют последнему выбору
- [ ] Pull-to-refresh (в том числе повторный, без дублирования запросов)

## 7. После релиза

- Мониторинг `/health` и `/ready` прокси.
- Резервная копия `.env` сервера и ключей подписи.
- Регламент обновления: новая версия APK с увеличенным versionCode, проверка на устройстве, загрузка в RuStore.
- При появлении публичного HTTPS-домена — переключить production `EXPO_PUBLIC_API_BASE_URL` и отключить HTTP в preview.
