# Релиз ScheduleMASU

Целевая площадка — **RuStore, Android**. iOS в текущий релиз не входит.

## 1. Решения до первой сборки

- **Application ID**: сейчас `com.horizon_spark.ScheduleMASU` (`app.json` → `android.package`).
  После первой публикации в RuStore менять нельзя — это будет другое приложение.
  Если нужен другой ID, поменяйте его до загрузки.
- **Название приложения**: `ScheduleMASU` — это имя в лаунчере. Название карточки в RuStore можно задать отдельно (например, «Расписание МАУ»).
- **Правообладатель/разработчик** в RuStore: аккаунт вуза или команды; от этого зависят реквизиты и политика конфиденциальности.
- **Политика конфиденциальности**: нужен публичный URL. Приложение отправляет LDAP-учётные данные в прокси и хранит токены в SecureStore — это нужно описать.
- **Поддерживаемые версии Android** и целевая аудитория.

## 2. Окружение EAS

В EAS Environment Variables должны быть заданы:

| Переменная | preview | production |
|---|---|---|
| `EXPO_PUBLIC_API_BASE_URL` | адрес прокси (можно HTTP, пока нет TLS) | **обязательно `https://…/api`** |
| `EXPO_PUBLIC_ALLOW_HTTP` | `1` (только пока прокси без TLS) | не задавать |
| `APP_VARIANT` | задаётся в `eas.json` | задаётся в `eas.json` |

`app.config.js` не даст собрать production-APK, если URL отсутствует или не HTTPS. `src/api/client.ts` дополнительно проверяет это в рантайме.

## 3. Сборка для RuStore

```bash
npx eas-cli@latest build --platform android --profile production
```

- `eas.json` для production собирает **APK** (RuStore принимает APK и AAB; APK проще по подписи).
- `autoIncrement: true` — versionCode увеличивается на стороне EAS.
- Подпись хранится в EAS. Сделайте резервную копию credentials:
  ```bash
  npx eas-cli@latest credentials -p android
  ```
- Потеря ключа подписи = невозможность обновлять приложение в RuStore.

## 4. HTTPS

Production-приложение обязано ходить только по HTTPS:

- в `EXPO_PUBLIC_API_BASE_URL` — домен с доверенным сертификатом;
- `usesCleartextTraffic` для production выключается автоматически (`app.config.js`);
- серверная часть: TLS-оверлей nginx, сертификат и деплой описаны в README `ExpressAPIGateway`.

Пока публичного домена нет, preview-сборка может работать по HTTP с `EXPO_PUBLIC_ALLOW_HTTP=1`. В production этот флаг не задаётся.
