# Фирменные ассеты МАУ

Источник: [фирменный стиль МАУ](https://mauniver.ru/info/design/logo).

- `logo-full.png` — цветной горизонтальный логотип для белого фона;
- `logo-full-white.png` — белая версия для фирменного синего;
- `logo-mark.png` — цветной знак;
- `logo-mark-white.png` — белый знак для синей шапки и splash.

Правила использования: цветная версия — приоритетно на белом фоне, белая —
на фирменном синем. Знак без текста допускается для небольших иконок.
Внешнее использование логотипа и графики согласуется с университетом:
`marketing@mauniver.ru`.
